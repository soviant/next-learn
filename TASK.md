# Technical Test: Add a Notes field to invoices

Work in the `dashboard/final-example` folder.

## What to do

Add an optional "Notes" field to invoices:

1. Add a `notes` text field to the invoice creation/edit form
2. Save the note (add a `notes` column if one doesn't exist)
3. Display the note on the invoice detail/list view, if present
4. Make sure existing functionality still works

## Time expectation

60-90 minutes.

## How to submit

1. Clone this repo (do NOT fork it). Do not publish your solution anywhere public.
2. Make your changes locally.
3. Record a short screen video (under 1 min) showing: creating an invoice with a note, and the note displayed in the list/detail view.
4. Zip your project (without node_modules and .next).
5. Reply to our email with the ZIP and the video.

Both are required. We recommend sending your submission within 48 hours of receiving this link. Earlier submissions are reviewed first.
